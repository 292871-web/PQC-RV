# Contributing

Thank you for your interest in contributing to this project! I always highly appreciate it when the community wants to help improve the codebase.

However, please note that **this project does not accept external Pull Requests (PRs).**

Because this repository uses a specific licensing model (free for hobbyists and small businesses under the PolyForm Small Business License, but commercially licensed for large corporations), I must maintain 100% strict ownership of the intellectual property. Accepting external code would require complex Contributor License Agreements (CLAs) and create legal friction. To keep things simple and legally safe, I develop and maintain all the code myself.

### How you can still participate

While I cannot accept direct code contributions, your feedback is incredibly valuable. You are more than welcome to:
* **Report bugs** by opening a GitHub Issue.
* **Suggest new features**, instructions, or optimizations in the Issues tab.
* **Discuss** the architecture and share your thoughts.

Thank you for understanding and for supporting the project!
